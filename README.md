# 🎹 鋼琴和弦大師 (Piano Chord Trainer)

一個基於 Web Audio API 開發的互動式鋼琴和弦練習系統。專為音樂學習者設計，透過直覺的鋼琴界面與即時音效反饋，幫助使用者掌握各種和弦組成音及其轉位。

## ✨ 核心功能

### 1. 雙八度互動鋼琴
*   **24 鍵模擬鍵盤**：支援兩個八度的完整顯示，黑白鍵佈局符合真實鋼琴比例。
*   **持續音效引擎**：點選琴鍵會持續發聲（Sustain），模擬按住鋼琴鍵的效果，方便聽辨和弦色彩。
*   **移動端優化**：針對平板觸控進行優化，支援多點觸控感應啟動音訊。

### 2. 多樣化練習範圍
*   **豐富的和弦庫**：包含大三、小三、屬七、大七、小七、減七、半減七等 9 種以上常用和弦。
*   **自定義過濾器**：使用者可以隨時複選想要練習的和弦種類。
*   **支援轉位 (Inversions)**：系統隨機出題，包含原位、第一轉位、第二轉位與第三轉位。

### 3. 精確的視覺反饋系統
系統在提交答案後會提供三種維度的回饋：
*   ✅ **實心綠 (Correct)**：特定位置的按鍵正確。
*   ❌ **實心紅 (Wrong)**：該位置按錯了，並伴隨紅色發光特效。
*   ░ **虛線框 (Missing)**：答案需要的音名，但在整個鍵盤上都沒有被按下。

### 4. 20 題挑戰模式
*   **計分機制**：每題 5 分，滿分 100 分。
*   **進度管理**：頂部即時進度條與題數顯示。
*   **結算畫面**：完賽後自動跳轉結算頁面，顯示總分與正確率。

*   **前端開發**: HTML5, CSS3 (Flexbox/Grid), JavaScript (Vanilla JS)

## 🎹 轉位判斷邏輯說明

本系統採用「音名比對 (Pitch Class Mapping)」作為主要判定標準。
*   **邏輯細節**：系統會生成特定轉位的音高陣列（例如 C 第一轉位為 E4, G4, C5），但在判定時，只要使用者在鍵盤上的任意八度按對了 E, G, C 三個音名，即判定為正確。
*   **顯示策略**：為了輔助學習，「遺漏 (Missing)」的虛線框會精確顯示在題目所要求的特定轉位位置上，引導使用者學習正確的 Voicing。

## 🚀 如何開始練習

1.  點擊 **START TRAINING** 解鎖音訊環境。
2.  觀察題目顯示的和弦名稱（如 `G#7`）與轉位要求。
3.  在鋼琴鍵盤上點選你認為正確的音符（音符會持續響起）。
4.  點擊 **CONFIRM & SUBMIT** 檢查答案。
5.  點擊 **NEXT QUESTION** 進入下一題，直到完成 20 題挑戰。
